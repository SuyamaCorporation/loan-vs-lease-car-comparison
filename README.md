# Car Loan vs Lease Cost Comparison

## 概要
車両価格・頭金・ローン金利・期間・リース月額・残価を入力し、総支払額・月額・残存価値を並列棒グラフで比較する純粋な教育ツール（実際の売買推奨なし）。

## 機能
- ローン計算（元利均等返済、月額・総支払額・総利息）
- リース計算（頭金+月額×期間）
- 資産売却後の実質コスト（ネットコスト）比較
- Chart.jsによる4項目並列棒グラフ
- 判定表示（ローン vs リース どちらが経済的か）

## 使い方
ローン側とリース側のパラメータをそれぞれ入力し「Compare」ボタンを押します。ローンは資産価値を差し引いたネットコストでも比較できます。
